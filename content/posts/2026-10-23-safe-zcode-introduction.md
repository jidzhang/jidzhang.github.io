Safe ZCode 是上游 [ZCode](https://github.com/zai-org/ZCode) 开源快照的下游分支，围绕隐私、可控性和中文使用场景做了一组补丁，跟随上游更新，代码在 [jidzhang/ZCode](https://github.com/jidzhang/ZCode)。

九月发布第一版时只支持 Windows；目前基线跟到上游 3.16.2，共发布 10 个版本，Windows、macOS、Linux 的 x64 与 arm64 均有安装包。实现方式与 Edge 之于 Chrome 类似：上游发布快照后合并，逐条重放本地补丁；上游已实现同类功能的，删除本地对应改动。

## 相较于官方版

**隐私默认收紧。** 模型遥测在打包环境写入关闭值；阿里云 ARMS 监控 SDK 换为零网络空实现；官方发行版构建期注入的 OTLP 上报地址，本项目不注入，安装包里没有可上报的目的地。启动时的七类后台请求（更新检查、升级提醒、灰度开关、帮助链接、模型列表、插件市场、远端小图标）默认全部停用，各自回落到本地数据；会话分享发布入口默认关闭。需要恢复时在 `~/.zcode/v2/setting.json` 里加 `"enableStartupOutbound": true` 并重启。

**日志可配置。** 上游保留期固定 14 天且没有级别开关。现在有两个设置项：`logLevel`（`error` / `warn` / `info`，默认 `info`）和 `logRetentionDays`（0–365，默认 14）。阈值同时作用于主进程、渲染进程转发的日志和 Host 服务层日志，日志只写本地目录、不上传。

**登录是选项，不是前提。** 上游逐步收紧账号体系：未登录可能被全屏拦截，token 过期弹全屏重登页；3.16.2 的手机远控改成账号 JWT，只用 API key 的用户直接无法使用。本项目过滤掉启动守卫与过期推送，只在用户主动登录、选择需要账号的模型或登出后重连时显示登录页；不登录也能使用全部本地功能。手机远控恢复了 3.15.1 的免登录配对链路（二维码携带 `hash`/`t`，relay 匿名注册），手机页版本固定到 3.15.1。更新通道独立，发布包只查本仓库的 GitHub Releases。

**飞书 / 微信通道更可靠。** 通道是客户端与飞书、微信官方服务器的直连，不经过任何中间域名。在此基础上：飞书 token 被服务端提前作废时自动续期重试，流式卡片熔断改为 60 秒半开可恢复（上游为永久闩锁，一次故障只能重启）；任务运行中发送的消息改为入队而非拒绝，桌面端发起的任务也能正确排队；工具调用摘要、报错、权限申请、状态预览四个出口统一做密钥打码，路径与链接保持原样。两个通道各有独立包，可挂到 `zcode --web` 后端用于无桌面部署。

**其他。** 运行时追问默认"引导"，回车直接发出；修复 Windows 打包脚本的两处失败与 PowerShell 输出编码；工具描述引导模型用 `rg --files` 找文件；资源管理器空白处右键补齐 `Directory\Background` 注册位，并修复 3.16 虚拟项目侧栏下打开目录不归属项目的问题；设置页"测试"按钮不再把输出预算写死为 1 token，reasoning 档位被拒时报错会指出具体档位。

## 已知缺失

**Computer Use 不可用。** 上游开源树中的 `@zcode/zcode-cua` 是 fail-closed 占位包，真实 `cua-helper` 运行时仅随官方闭源安装包分发。发布包不包含该组件，Browser Use 不受影响。本地自建打包可从官方安装包提取产物注入，该能力在仓库中，但产物不入库、CI 与发布包也不带。

另需说明：手机远控依赖官方 relay 与 3.15.1 手机页资源，官方下线即失效；使用 GLM Coding Plan 账号登录属于非官方工具的个人自用场景，条款处于灰区，仅使用 API key 的路径不存在该问题。除此之外，桌面端、CLI/TUI、Web、插件与 Gen UI、远程工作区、手机远控、飞书/微信、Coding Plan 登录与额度查询均可替代官方版。

## 使用与参与

安装包见 [Releases](https://github.com/jidzhang/ZCode/releases)。安装后即为上述默认配置。

欢迎参与：在你自己的平台上实测并提交复现步骤与日志（跨平台问题最缺实测）；提交小而具体的 PR；上游发布快照后协助复核合并语义；修正文档与翻译中的过期描述。项目提交前运行全量单测与架构检查，三平台由 GitHub Actions 构建发布。

官方版对多数用户仍是合适选择。若在意 AI 客户端的出站行为、需要不强制登录的版本，或对飞书/微信通道的可靠性有要求，可以试用 Safe ZCode。
